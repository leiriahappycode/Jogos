👁️ As sequências de símbolos

Nas seis sequências do desafio original existe um símbolo incorreto em cada uma. Ao identificar o primeiro erro de cada sequência, obténs as palavras da segunda pista.

PISTA 3 DE 4 · CÓDIGO BINÁRIO

💻 Descobre a cor do cabelo

Converte cada linha de código binário numa imagem: 1 representa um quadrado preto e 0 representa um quadrado branco. As seis imagens formam uma palavra.



PISTA 4 DE 4 · CÓDIGO ASCII BINÁRIO

📡 A disciplina secreta

Usa a tabela de conversão do dossier para transformar cada grupo de 8 bits numa letra.

Código:
01010011  01000011  01001001  01000101  01001110
01000011  01000101
Consultar a tabela de letras (A–Z)

Cada letra corresponde a um código binário de 8 bits. Por exemplo, 01000001 = A; 01000010 = B; 01000011 = C. Continua a sequência para descodificar os restantes grupos.
